## 一键仿真

```bash
cd /home/andy/python_code/dartG1-main/GRIT_teleop_deploy/sim2real
bash run_gt.sh 005225 --slow --sim
```

替换 GT ID；必须带 `--slow` 才是降速版，不带则使用原速版。
每次运行一个，Ctrl+C 中断。不需要启动真机 bridge。
`--headless` 无窗口，`--dry-run` 仅打印命令。
仿真使用本机 UDP 65100–65111，不使用真机 55001/55002。

转换文件与审计记录：`gt_hml3d_arm_leg_slow/prepared/GT_ID/`。
其中 `motion.npz` 为降速动作，`prepared.json` 记录倍率和源文件签名，
`latest_evaluation.json` 为最新完整性/稳定性/候选判定，`eval_*/` 保留每次日志和逐帧指标。
原速文件仍在 `gt_hml3d_arm_leg/`。

## 真机条件

沿用 [原 GT 真机手册](GT_ARM_LEG_MANUAL_ZH.md) 的 bridge、吊架和手柄流程。
两段 5 秒插值、单次播放、SELECT 锁存阻尼不变。
只有降速版自己的结果为无错误、完整记录、PASS 且 CANDIDATE_TIER1/2 才能进入真机入口；
不能沿用原速或生成组的结论。没有放宽阈值，没有 bypass 开关。

先检查资格，不启动控制进程：

```bash
bash run_gt.sh 005225 --slow --hardware --dry-run
```

只有通过筛选，且完成 GUI 回放、物理支撑、净空、网络和急停检查后，
才将 `--dry-run` 去掉，使用既有 bridge。START 到默认站姿，站稳后短按 A 播放。
SELECT 是阻尼而非位置锁定，不替代物理急停。
本次脚本仅自动执行仿真，不自动启动任何真机进程。
